# Secamoto demo

Design demo for secamoto.hu (Seca motorcycle gear, UNAS webshop). Read `BRIEF.md` first: it holds the
decided style and scope. Static site, no framework, no runtime dependencies.

## Files
- `data/site.json`: company facts, contact, shipping, payment, promo, links. Never hard-code these in pages.
- `data/catalog.json`: categories + products (generated by `tools/import_media.py`, then hand-editable).
- `data/modes.json`: riding modes (RAIN/ROAD/URBAN/SPORT/TRACK): copy, photo, gear, revs, and the regex that
  assigns products to a mode.
- `tools/build.py` (stdlib only): writes `index.html`, `kategoria/*.html`, `mod/*.html`, `termek/*.html`,
  `robots.txt`. Generated pages are committed. Never edit them by hand.
- `tools/import_media.py` (needs Pillow): one-off import from `C:/Claude/Repos/_media/secamoto` (scrape of
  2026-10-19) into WebP images and `data/catalog.json`.
- `css/style.css`, `css/fonts.css`, `js/site.js`, `fonts/` (self-hosted Chakra Petch + IBM Plex Sans Condensed).

## Workflow
1. Change data, CSS or JS. 2. Bump `ASSET_VERSION` in `tools/build.py` when CSS/JS changes.
3. `python tools/build.py`. 4. Preview: `python -m http.server 8762` in the repo, open http://127.0.0.1:8762/.

## Rules
- Buy buttons link to the real product on secamoto.hu; this site sells nothing.
- Footer keeps `Üzemeltető: mukodoweb.hu` and the "Dizájn demó" note.
- `noindex` stays on (`site.json`) until the owner approves.
- Promise only what the shop states: no free-shipping limit exists, pickup is by appointment only.
